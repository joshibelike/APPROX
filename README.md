# APPROX — нейросеть аппроксимирует функции

Интерактивная версия практической части работы «Аппроксимация функций с помощью нейронных сетей»
(Турлова Мария, 10А, МОАУ «Лицей №8», Оренбург, 2026).

Нейросеть из работы (PyTorch) переписана на чистый JavaScript — без библиотек:

| Python (работа)                      | Здесь (`src/nn.js`)                          |
|--------------------------------------|-----------------------------------------------|
| `SimpleNeuralNetwork(hidden, act)`   | `MLP` — 1 → скрытые слои → 1, ReLU/tanh/sigmoid |
| `nn.Linear` (инициализация)          | U(−1/√fan_in, 1/√fan_in)                      |
| `nn.MSELoss`                         | MSE по мини-батчу                             |
| `loss.backward()`                    | ручное обратное распространение ошибки        |
| `optim.Adam(lr=0.001)`               | Adam (β₁=0.9, β₂=0.999, ε=1e-8)               |
| `DataLoader(shuffle=True)`           | `Trainer.trainEpoch()` — перемешивание + батчи |

Обучение идёт в Web Worker (`src/worker.js`), поэтому интерфейс не зависает.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статический сайт в dist/
npm test         # проверка градиентов + эксперименты из работы
```

## Что есть на сайте

- **Лаборатория**: функции f₁, f₂, f₃ из работы + ещё три, своя формула, рисование своих точек;
  число точек, шум, архитектура (слои/нейроны), активация, батч, lr, число эпох;
  график с экстраполяцией, зонд при наведении, кривая ошибки, схема весов сети.
- **Сравнение**: три сети разного размера на одних данных (эксперимент о переобучении).
- Светлая/тёмная тема, адаптация под телефон, `prefers-reduced-motion`.
