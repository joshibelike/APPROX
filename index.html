    02 / Сравнение

    Три сети — одни данные

    Эксперимент о переобучении из работы: мало точек, шум и три сети разного размера. Малая видит только общий тренд, большая «запоминает» каждую точку — а между ними рисует кашу.

    03 / Как это работает

    Алгоритм из работы — в браузере

    Нейросеть написана на чистом JavaScript без библиотек: прямой проход, обратное распространение ошибки, оптимизатор Adam и мини-батчи реализованы вручную. Обучение идёт в Web Worker, поэтому страница не зависает.

    1. 01

      Данные

      Берём функцию на отрезке, ставим n точек по сетке (linspace) и добавляем гауссов шум — как в реальных измерениях.

    2. 02

      Прямой проход

      Полносвязная сеть 1 → скрытые слои → 1. Каждый нейрон считает взвешенную сумму входов со смещением и пропускает через ReLU, tanh или sigmoid.

    3. 03

      Ошибка

      Сравниваем ответ с эталоном: MSE = среднее (ŷ − y)² по мини-батчу. Чем меньше, тем ближе кривая к точкам.

    4. 04

      Обучение

      Обратное распространение вычисляет вклад каждого веса в ошибку, а оптимизатор Adam (lr = 0.001) сдвигает веса. Повторяем сотни эпох.

    1 → N → 1Один вход x, один выход ŷ — сеть строит график функции одной переменной.
    ПереобучениеЕсли параметров слишком много, а точек мало, ошибка на обучении ≈ 0, а между точками — каша. Следите за кривой «Тест».
    ЭкстраполяцияВне области обучения сеть ничего не «знает»: ReLU-сеть продолжит прямой линией, tanh — «выйдет на плато».
